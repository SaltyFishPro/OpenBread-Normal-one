# 主菜单预览

打开 [main_menu_mock.html](main_menu_mock.html) 查看预览，方向键上下切换，Enter 确认。

屏幕逻辑尺寸为 384×168；文字只使用 14、20、24 像素，菜单名称固定为 20 像素。
浏览器中的文字由系统字体示意，不代表 SD 卡点阵字体的实际字形。

焦点舞台使用固件主菜单的全部 13 个点阵动画。图标来源、顺序和帧间隔读取自
[HomePage.cpp](../../src/ui/pages/HomePage.cpp)，尺寸读取自
[ThemeMono.h](../../src/ui/ThemeMono.h) 的 `kIconFocusSize`（当前为 42）。
导出时按 [IconBitmap.cpp](../../src/ui/IconBitmap.cpp) 的整像素取样方式缩放；
网页将图标反白以适配黑色卡片，不裁切原始图标边界，不进行平滑处理。
浏览器动画帧调度受运行环境影响，不表示固件实际刷新性能。

更新固件图标后，在仓库根目录执行：

```powershell
python tools/home_menu_preview/export_icons.py
```

脚本支持当前原始 1bpp 和 packed RLE 资源，将全部动画帧嵌入 HTML。
生成后的网页可单独打开，不需要网络请求或本地服务。
切换到目录方案或隐藏网页时停止动画定时器；启用系统减少动态效果设置时只显示首个非空帧。

## 低功耗与浅睡预览

预览的空闲阈值与当前固件一致：

- [HomePage.h](../../src/ui/pages/HomePage.h) 的 `kIdleAnimationTimeoutMs` 为 4000ms：
  图标停在最后显示的帧，不回到封面帧。
- [UiManager.cpp](../../src/ui/UiManager.cpp) 的 `kAutoSleepTimeoutMs` 为 20000ms：
  无操作达到此阈值时，播放一次入睡过渡。固件在字体加载、音频、无线等任务活动时会阻止浅睡；
  此网页只模拟没有后台任务的主菜单。

新增的入睡视觉方案仅在本 HTML 中实现：720ms 内，信息区、分割线、菜单与刻度一起向右平移
256px。分割线作为扫描线推出菜单并移出右边界，时间日期区最终位于 x=256..384；
左侧 x=0..256 为宠物的空白占位，不绘制图标或占位文字。
入睡后停止图标动画和过渡帧回调，只保留分钟更新；没有循环屏保动画。
网页时钟使用浏览器本地时间，电量为示意值。

首次按键只唤醒，反向恢复原菜单与焦点，恢复完成后再次按键才执行操作。
入睡过程中也能按键从当前位置反向恢复，持续按住唤醒键不会重复触发菜单操作。
上/下切换焦点，Enter/空格确认，左键返回；主菜单上返回保持原页。
“预览浅睡”按钮可跳过等待，位于设备屏幕之外。
减少动态效果设置会跳过扫描过渡；网页隐藏时停止定时器，重新显示时根据空闲时长恢复状态。

固件当前的浅睡与分钟唤醒逻辑见 `UiManager::enterSleep`；此预览没有改动硬件驱动、
唤醒引脚、供电策略或固件浅睡布局。固件接入该过渡时，需要在关闭外设之前完成一次动画；
这会增加约 720ms 的入睡前运行时间，睡眠期间无需保持动画任务。

## XMB 方案

[xmb_menu_mock.html](xmb_menu_mock.html) 是独立的 XrossMediaBar 方案，原有的
[main_menu_mock.html](main_menu_mock.html) 保持不变。XMB 的横轴使用固件的 13 个主菜单分类，
纵轴使用现有二级目录内容：设置、音乐、阅读、专注时钟、无线功能、游戏，以及闹钟、课程表、
Api 统计板、答案之书、今日抽签、电脑状态看板和 SD 卡转 USB 的直接入口。

主分类只有当前焦点图标下方显示 14 号名称，不显示分类计数。设置、音乐、阅读、无线功能和游戏
显示有限的子项目列表；到第一项或最后一项时，上下键停止，不进行首尾循环。专注时钟、闹钟、
课程表、Api 统计板、答案之书、今日抽签、电脑状态看板和 SD 卡转 USB 是直接入口，没有子分类，
因此不显示纵向子分类区域。

本版参考了 [OpenXMB](https://github.com/phenom64/OpenXMB) 的公开界面截图：顶部状态信息、
中央横向图标带、焦点图标下的分类名称、下方纵向子项目和贯穿背景的波形线。针对本项目的
384×168 单色屏，波形改为黑底上的白色细线，横向只保留五个可见图标，左右图标使用固件
动画的静态封面帧，焦点图标继续播放动画。

顶部电量、时间、日期、当前主分类名称和所有子分类名称统一使用 14px。子分类不再绘制右侧
横线，焦点状态只通过图标尺寸和文字明暗区分。

主分类焦点图标中心固定在 x=48，与下方子分类图标中心对齐；其他主分类图标从焦点向右排列，
形成一条连续的 XMB 横向导航轴。

子分类左侧使用 14px 两位数字索引（01、02、03），不使用方框图标；焦点行只提高数字和文字
的明暗，不增加额外边框或横线。

主分类左右切换使用约 180ms 的短距离横向滑入，子分类上下切换使用约 150ms 的纵向滚动；
只在按键操作时播放，不创建持续动画任务。到达子分类首项或末项时不会触发无效动画，系统启用
“减少动态效果”时会自动关闭这些过渡。

← / → 切换分类，↑ / ↓ 选择分类内项目，Enter 确认，Backspace 返回顶层；网页外的按钮提供同样的操作。
焦点分类图标和原方案共用固件真实点阵资源。XMB 只展示交互和排版方案，不改变固件页面逻辑。
更新固件图标后执行 `python tools/home_menu_preview/create_xmb_preview.py` 重新生成该文件。
