# 设备端 WiFi 配网与连接记录

设备端以 [HTML 预览](../tools/home_menu_preview/wifi_device_mock.html) 的 384×168 黑底界面为布局依据。列表每屏 3 行，网络名称使用完整 20 号字库，固定提示使用 14-ui，流程标题使用 24-ui，扫码页标题使用 20-ui。二维码保持 111×111，包含四模块留白区，内容为当前设备实际热点名称的 WiFi 加入信息。

## 模块归属

- `src/ui/pages/WifiPage.*`：列表、详情、满额替换、确认与流程页面，管理页面私有焦点和字体引用。
- `src/services/WifiNetworkStore.*`：固定容量 5 条 NVS 记录，包含凭据与最后成功连接时间，不负责联网或绘图。
- `src/services/WifiProvisionService.*`：保存网络直连、手机配网、连接结果、校时交接和无线资源回收。
- `src/ui/UiManager.*`：按键路由、页面切换和字体生命周期。

## 按键与持久化

上下键移动焦点，OK 执行，左键返回上一级或取消；所有二次确认默认选中“取消”。历史列表上下不循环，满额时先选择替换目标，新网络连接成功后才提交替换。相同 SSID 更新密码并移至最前，不重复保存。失败、取消或存储写入失败均不删除原记录。

旧固件 `wifi/ssid` 与 `wifi/pass` 在首次读取时迁移至 `wifi/networks`，新列表成功写入后才删除旧键。记录列表以单个带版本标记的固定大小 blob 提交，读取时检查容量、名称与重复项；即便列表为空也保留权威记录，防止被忘记的旧网络重新出现。

时间有效时记录当次连接的本地日期和时分，时间无效则显示“上次成功连接时间未记录”。OTA 和手动校时使用最近成功保存的网络，不使用最近失败尝试的凭据。没有新增密码展示或导出接口。

## 无线生命周期

进入页面不会开启 WiFi。用户确认添加网络后才开启配网 AP；直接连接已保存网络时仅开启 STA。手机配网连接成功后，AP 保持 6 秒，再复用 STA 完成一次校时并关闭无线。已保存网络连接成功后直接校时，不开启 AP。连接失败时保留历史，STA 直连失败关闭无线，手机配网失败保留 AP 供修改表单，最多等待 5 分钟。

取消连接、取消校时、等待超时或页面操作结束时关闭对应无线资源，不在后台自动重连。因此退出后不会保持网络在线；下次校时或 OTA 需要重新连接。首次开机字体下载继续使用原有 `FontSetup` 交接方式，连接成功后只关闭 AP，保留 STA 给下载服务，下载完成后再关闭无线。

没有修改引脚、WiFi 驱动初始化或硬件总线配置。串口使用统一 `[WIFI]` 日志，记录来源、失败原因、保存结果与关闭阶段，不输出密码；沿用 `OB_LOG_LEVEL` 控制等级。

### 配网确认响应优化（2026-11-14）

固定字体现在由 `UiManager` 管理：14-ui 保持已有字形缓存，20/24-ui 在主菜单分步载入 PSRAM（每份最多 128KiB），校验通过后关闭 SD 文件。WiFi 页面只引用这些快照，退出后不释放，也不再额外准备页面私有的 62 个字形。完整流程见 [字体生命周期](SD_BITMAP_FONTS.md#字体加载与复用2026-11-14)。

空记录、添加确认、热点准备及扫码页不打开完整字库；有历史列表或详情时按需打开完整 20 号，确认说明或连接状态需要显示用户网络名称时才打开完整 14 号。首次仍需要 CRC，随后在同一 SD 会话内复用；动态内容使用两份各 125,792-byte 有界缓存，离页释放，不缩减名称的字符范围。

“开启配网热点？”的固定说明使用常驻 14-ui；包含用户网络名称的确认说明仍使用完整 14 号。上下移动确认焦点仅在现有缓冲绘制两个按钮，面板沿用已验证的整屏推送，避免窄窗口映射风险。主机检查完整弹窗和焦点绘制均为 0 次 SD 读取，局部结果与整页绘制逐字节一致。

确认后先绘制并推送“正在开启热点”，UiManager 在推送完成后调用页面的 `afterPresent`，再由服务同步初始化无线；保留原替换、重配与首次开机流程。没有新增后台任务，真实热点启动耗时仍取决于驱动。日志 `portal start requested` 与 `portal ready elapsed_ms=... cleanup_ms=... driver_ms=...` 可区分请求、清理、驱动及总耗时，失败日志包含总耗时；热点 5 分钟超时从初始化完成后起算。

## 字体部署

新增文案已生成 815 个固定码点，14-ui 常驻缓存 61,940 bytes。SD 卡需更新三个 `font-*.ui.bin`，完整字库仍保留。首次开机必需六份字体文件，大小和哈希见 [首次开机字体安装](FIRST_BOOT_FONT_SETUP.md)。

`tools/font_builder/output/normal-one-fonts-wifi.zip` 内含 `Font/` 文件夹：可解压到 SD 根目录。服务器上传该文件夹内的文件至现有字体目录；三个 UI 子集有更新，需要同步清理对应 CDN 缓存。本地生成文件不代表服务器已经上传成功。
