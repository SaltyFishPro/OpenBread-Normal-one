# 音乐页面与歌词

音乐列表每页显示 3 首。上下键选择歌曲，OK 播放；右键进入收藏和音量工具，Left 返回。播放器上下键选择控制，OK 确认，Left 返回列表并继续播放；列表 Left 退出并停止播放。

将 UTF-8 歌词与音频放在 SD 卡 `/music/` 下，使用相同文件名、小写 `.lrc` 扩展名，例如 `晴天.mp3` 和 `晴天.lrc`。支持分钟、秒、百分秒或毫秒时间标签，一行多个标签和乱序标签。文件最大 64 KiB，最多保留 128 条；原始行超过 255 字节则跳过，文本最长 95 字节并保持 UTF-8 边界。

每 20ms 最多读取 256 字节，加载后关闭文件，缓存约 12.5 KiB PSRAM，切歌、停止或退出时释放。当前歌词使用完整 20 号字库，上下歌词和歌名使用完整 14 号；缺少歌词时显示暂无歌词。串口 `[LYRICS]` 记录加载和错误，可通过 `OB_LOG_LEVEL` 控制。

本次没有修改 SD 总线、音频引脚或 DAC 控制。音频、字库和歌词共享 SD，单次读卡可能阻塞，真实播放有无卡顿、爆音或按键延迟需要实机验证。播放器每 250ms 更新；降低刷新频率可以节电，但歌词切换会更不流畅。

主机测试覆盖 LRC 解析、顺序、缺文件、加载和资源释放。`tools/ui_sd_font_preview` 使用生产页面和绘图驱动生成 `tmp/ui-sd-font/music-*.png`，音频服务为测试替身，不能代替实机音频验证。
